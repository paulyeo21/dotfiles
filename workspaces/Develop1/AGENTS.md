# Personal Workspace Rules

Applies to repositories under `~/Develop1/`.

## Context scope

- Context scope is `personal`.
- Session handoffs live in the Obsidian vault under `sessions/personal/`.
- Cross-repo project specs live under `projects/personal/`.
- Reusable personal knowledge lives under `topics/personal/`; use
  `topics/shared/` only when it genuinely applies to work too.
- Keep work-specific context out of the personal namespace.

## Workflow

- Repo-level `AGENTS.md` or `CLAUDE.md` supplies that repo's commands,
  architecture, tests, and contribution rules; follow it before editing.
- For personal work spanning repositories, use the active project spec as
  the source of truth for goal, contracts, and initiative progress.
- Keep process proportional to the project while still following the global
  planning, testing, and code-editing rules.
